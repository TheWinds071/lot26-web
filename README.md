# 🌊 双水槽智能水循环监测与自动控制系统 (Dual-Tank Smart Water Circulation SCADA)

本项目是一套集 **TCP 数据采集**、**双水槽闭环自控规则引擎**、**SCADA 工业数字孪生大屏** 于一体的智能水循环监测与控制系统。

系统由 **2 个水槽**（水槽1 / 供水与加热主槽、水槽2 / 工艺与回水循环槽）、**2 个温度传感器**（分别监测水槽1与水槽2水温）、**槽间管道压力传感器**、**槽间循环流量计** 与 **循环水泵及加热模块** 构成。系统通过 TCP 客户端接收实时遥测数据，并在后端自控规则引擎的作用下，自动调控水泵转速与加热功率，实现槽间水流循环与双槽水温恒温控制。

## 二、核心功能特性

1. **双水槽与多传感器实时采集**:
   - **水槽 1 水温**（$T_1$）：实时监测供水/主加热水槽温度。
   - **水槽 2 水温**（$T_2$）：实时监测工艺/回水水槽温度。
   - **槽间管道压力**（$P$）：实时监测泵出水与管路承压状态（$\text{MPa}$）。
   - **槽间循环流量**（$F$）：实时监测双槽间水体流动速率（$\text{L/min}$）。
2. **双槽水流自控与闭环恒温**:
   - 水温过低时自动启动循环水泵与加热模块，驱动水槽1热水流入水槽2进行混合与均温。
   - 双水槽温差过大（$\Delta T > T_{\text{diff\_max}}$）时触发平衡预警，加速循环混合。
   - 达到目标温度后自动切断加热，维持管路循环。
3. **毫秒级安全联锁保护**:
   - **超压保护**：管道压力超过 $P_{\max}$ 时立即停泵停加热，防止爆管。
   - **超温保护**：任一水槽水温超标立即切断加热。
   - **防干烧保护**：水泵运行但流量不足时强制关闭加热。
   - **紧急急停**：一键锁定所有执行机构。
4. **数字孪生 SVG 拓扑仿真**:
   - 动态双水槽液位呼吸与温度探针指示。
   - 水泵叶轮根据设定转速动态旋转。
   - 槽间管路流体粒子随流速动态流动，加热工况下管路呈现热流动渐变特效。

## 三、TCP 通信协议规范

TCP 服务端默认监听端口：`8888`（可通过环境变量 `TCP_PORT` 自定义）。

### 1. 客户端上行报文 (Telemetry -> Server)

支持两种格式（每条报文以换行符 `\n` 结尾）：

#### 格式 A：标准 JSON 报文（推荐）
```json
{
  "device_id": "DUAL_TANK_STATION_01",
  "temp_tank1": 46.5,
  "temp_tank2": 42.0,
  "pressure": 0.35,
  "flow_rate": 18.5,
  "water_level_tank1": 80.0,
  "water_level_tank2": 65.0
}
```

#### 格式 B：CSV / 紧凑文本格式
4 字段格式（水槽1温度, 水槽2温度, 压力, 流量）：
```text
46.5, 42.0, 0.35, 18.5
```

### 2. 服务端下行反馈与控制指令 (Server -> Client/PLC)

服务端接收数据后每帧自动返回下行 ACK 与当前执行器指令：

```json
{
  "status": "ACK",
  "pump_active": true,
  "pump_speed": 60,
  "heater_active": true,
  "heater_power": 100,
  "emergency_stop": false,
  "auto_mode": true,
  "timestamp": "2026-08-29T13:21:31.650000"
}
```

## 四、双水槽自动控制与安全联锁策略

| 保护/控制项 | 触发条件 | 动作与策略 | 告警级别 |
| :--- | :--- | :--- | :--- |
| **管道超压保护** | 压力 $\ge P_{\max}$ (默认 $0.80\,\text{MPa}$) | 立即停止水泵与加热器，防止管道爆裂 | **CRITICAL** |
| **水槽超温保护** | 任一水槽水温 $\ge T_{\max}$ (默认 $75.0\,\text{°C}$) | 强制切断加热模块输出 | **ERROR** |
| **双槽温差预警** | $\|T_1 - T_2\| \ge \Delta T_{\max}$ (默认 $15.0\,\text{°C}$) | 触发温差过大预警，建议加大水泵循环 | **WARNING** |
| **低流量/防干烧** | 水泵运行且流量 $< F_{\min}$ (默认 $5.0\,\text{L/min}$) | 强制切断加热模块输出，防止干烧损坏 | **WARNING** |
| **低温加热与水流循环** | 水温 $\le T_{\min}$ (默认 $45.0\,\text{°C}$) 且处于自控模式 | 启动水泵并开启加热器（100% 功率）促进双槽热交换 | **INFO** |
| **目标恒温到达** | 平均水温 $\ge T_{\text{target}}$ (默认 $55.0\,\text{°C}$) 且处于自控模式 | 自动关闭加热模块 | **INFO** |
| **紧急急停** | 外部急停按钮按下 | 强制锁定所有输出为 OFF，禁止手动启动 | **CRITICAL** |

## 六、快速启动与操作指南

### 1. 启动后端服务 (FastAPI + TCP Server)

打开终端 1：
```bash
cd backend
# 首次运行同步依赖
uv sync

# 启动后端 (API 端口: 8000, TCP 端口: 8888)
uv run uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
```

### 2. 启动前端可视化界面

打开终端 2：
```bash
# 根目录下启动 Vite 开发服务器
npm run dev
```
打开浏览器访问：`http://localhost:5173`。

### 3. 启动双水槽物理仿真客户端

打开终端 3：
```bash
cd backend
# 运行双水槽物理仿真器 (模拟两水槽热交换、水泵输水与管路压力/流量)
uv run python simulator.py --interval 1.0
```

> **单次测试**：
> ```bash
> cd backend
> uv run python client_test.py '{"temp_tank1": 42.0, "temp_tank2": 38.0, "pressure": 0.35, "flow_rate": 18.0}'
> ```

## 七、API 与 WebSocket 接口

### REST 接口

- `GET /api/status`: 获取系统实时状态（双槽遥测、执行器状态、阈值配置、未恢复告警、TCP连接状态）
- `GET /api/history`: 获取近 120 组遥测时序数据
- `GET /api/alarms`: 获取告警历史
- `DELETE /api/alarms`: 清空告警记录
- `POST /api/control/mode`: 切换模式 `{"auto_mode": true | false}`
- `POST /api/control/pump`: 手动控制水泵 `{"active": true, "speed": 80}`
- `POST /api/control/heater`: 手动控制加热器 `{"active": true, "power": 100}`
- `POST /api/control/emergency_stop`: 触发/解除急停 `{"emergency_stop": true | false}`
- `GET /api/config/thresholds`: 获取自控阈值参数
- `POST /api/config/thresholds`: 修改保存自控阈值参数

### WebSocket 接口

- `ws://localhost:8000/ws/telemetry`: 全双工实时数据流推送与远程控制通道。
